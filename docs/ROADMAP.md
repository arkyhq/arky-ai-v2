Reddit and Google Trends collection, deduplication, entertainment filtering, deterministic ranking, cache support, and pipeline metrics.

Editorial analysis, Groq JSON handling, schema repair, deterministic fallback, and editorial output generation.

### v0.4 Script Strategy

Deterministic strategy mapping, validation, optional AI refinement, and strategy orchestration.

Script blueprint mapping, blueprint validation, narration generation, narration output validation, and script orchestration.

Voice constitution, deterministic voice mapping, blueprint validation, optional voice transformation, output validation, and Creator Voice orchestration.

Visual constitution, deterministic visual mapping, visual blueprint validation, AI visual planning, output validation, fallback planning, and visual planning orchestration.
